**🎹 Decent Sampler Instrument Library** is the complete English-language guide to building, organizing, and playing a Decent Sampler instrument library. Learn how to create `.dspreset` files, map samples across keys and velocities, add round-robin and release triggers, design a custom UI, and package your library for distribution. Built for sound designers, composers, and producers who want a free, cross-platform sampler workflow. **Completely free.** No signup. No paywall. No hidden chapters.

## ❓ What Is Decent Sampler

| **Term** | **Description** |
|-----------|-----------------|
| **.dspreset** | Instrument preset file |
| **Sample** | Audio file |
| **Zone** | Key/velocity range |
| **Round-robin** | Alternate samples |
| **Release trigger** | Key-up sample |
| **UI** | Custom background |

**Why use it?**
- ✅ Free sampler
- ✅ Cross-platform
- ✅ Simple XML format
- ✅ Custom UI
- ✅ Free guide

## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Samples not found** | Use relative paths |
| **No sound** | Check zone mapping |
| **Clicks** | Add fade in/out |
| **UI missing** | Check file path |
| **Round-robin fails** | Verify group IDs |
| **Load error** | Validate XML |
